# 괴물

> 사람들은 그것을 괴물이라 불렀다.

중편소설 · 주인공 **언년이**

---

## 줄거리

가뭄이 삼 년째 이어지던 해, 강원도 산골 솔골.

열여섯 살 종 **언년이**는 갓난아기 때 검은재 귀신바위 아래 눈구덩이에서, 얼어 죽은 어미 곁에 홀로 따뜻한 채로 발견된 아이다. 마을 사람들은 그녀를 '산이 내놓은 것', 괴물이라 부른다.

마을의 가축이 하나둘 찢겨 죽고, 머슴의 일곱 살 난 아들이 사라진다. 언년이는 그 아이가 산이 아니라 사람의 손에 팔려 갔다는 것을 안다. 그러나 종의 말은 아무도 믿지 않는다. 만신은 산이 빌려준 것을 돌려받으려 한다고 말하고, 언년이는 제물이 되어 한겨울 검은재에 묶인다.

그 밤, 언년이는 진짜 괴물을 만난다.

## 등장인물

| 이름 | 소개 |
| --- | --- |
| **언년이** | 윤 진사 댁 종. 열여섯. 사내 둘 몫의 일을 하고 추위를 타지 않는다. 불빛을 받으면 눈이 호박빛으로 빛난다. |
| **윤재희** | 윤 진사의 막내아들. 열 살. 몸이 약하고 언년이를 누이처럼 따른다. |
| **윤 진사** | 솔골의 양반이자 땅 주인. 체면을 목숨처럼 여긴다. |
| **삼월 할멈** | 부엌일을 하는 늙은 종. 언년이를 젖동냥해 키우고 이름을 지어 주었다. |
| **박 포수** | 늙은 사냥꾼. 열여섯 해 전 눈 속에서 언년이를 찾아냈고, 그날 본 것을 아무에게도 말하지 않았다. |
| **최 마름** | 윤 진사 댁 땅을 관리하는 마름. |
| **돌쇠 · 막동이** | 진사 댁 머슴과 그의 일곱 살 난 아들. |
| **황 만신** | 고개 너머 신당의 무당. |
